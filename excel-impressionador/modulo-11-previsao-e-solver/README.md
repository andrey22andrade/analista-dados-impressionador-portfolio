# 📘 Módulo 11 — Previsão e Solver

---

## 📌 Contexto do Módulo

Décimo primeiro módulo da trilha Excel Impressionador. Cobre as ferramentas de análise "e se" e de otimização do Excel — Solver (maximização e minimização com restrições), Planilha de Previsão, Gerenciador de Cenários, Atingir Meta e Tabela de Dados — usadas para projetar resultados futuros e encontrar a melhor combinação de valores para um objetivo.

## 🎯 Objetivo

Desenvolver conhecimentos práticos e operacionais relacionados a:

- Entender o que é o Solver e quando usá-lo
- Resolver problemas de maximização (ex.: lucro) e minimização (ex.: custo) com restrições
- Criar uma Planilha de Previsão a partir de uma série histórica de dados
- Comparar hipóteses com o Gerenciador de Cenários e gerar um resumo dos cenários
- Descobrir o valor de entrada necessário para atingir um resultado com Atingir Meta
- Simular vários valores de entrada de uma só vez com a Tabela de Dados

## 🧠 Conceitos Abordados

### 🔹 Solver

Suplemento do Excel que encontra o valor ideal de uma célula-objetivo (maximizar, minimizar ou atingir um valor) alterando outras células, respeitando restrições definidas pelo usuário. Praticado em problemas de maximização de lucro (definir a produção de cada produto respeitando um limite de espaço) e de minimização de custo (definir a quantidade de cada ingrediente de uma mistura com quantidade total fixa e limites mínimo e máximo por ingrediente).

### 🔹 Planilha de Previsão

Gera automaticamente uma projeção futura a partir de uma série histórica com datas (por exemplo, visitas diárias), exibindo o valor previsto e os limites de confiança superior e inferior em um gráfico.

### 🔹 Gerenciador de Cenários

Permite salvar diferentes conjuntos de valores de entrada (por exemplo, quantidade total e preço unitário) como cenários nomeados, alternar entre eles e gerar um **resumo** comparando os resultados de cada cenário lado a lado.

### 🔹 Atingir Meta

Descobre qual valor de uma célula de entrada produz um resultado desejado em uma célula de fórmula — por exemplo, qual preço unitário é necessário para atingir uma determinada receita ou lucro.

### 🔹 Tabela de Dados

Calcula o resultado de uma fórmula para vários valores de entrada de uma só vez, montando uma tabela de simulação sem precisar alterar a planilha manualmente a cada teste.

## 🧪 Aplicação Prática (Exercícios)

1. **Solver (Pasta de Trabalho 1)** — dois problemas: maximização de lucro de uma loja que vende computador, mouse e teclado (considerando custo, lucro e espaço unitários), e minimização de custo de uma mistura de 150 kg com arroz, milho, cevada e farelo de trigo, respeitando as quantidades mínima e máxima de cada ingrediente.
2. **Planilha de Previsão (Pasta de Trabalho 2)** — série histórica de visitas diárias a partir de 01/01/2021, com quase 500 registros, usada para gerar a projeção de visitas futuras.
3. **Gerenciador de Cenários e Atingir Meta (Pasta de Trabalho 3)** — modelo de receita mensal com sazonalidade (percentual da quantidade total vendido em cada mês), preço unitário e custo, com abas para cenários, meta e dois casos de dados, calculando receita total, custo e lucro em cada situação.
4. **Exercícios finais** — dois exercícios de fixação: (1) uso do Solver para definir a combinação mais lucrativa de TVs, Blu-Ray players e controles remotos, respeitando o estoque limitado de peças; (2) criação de três cenários variando quantidade vendida, custo unitário e preço unitário, com resumo comparando a margem de lucro de cada cenário.

A Tabela de Dados foi praticada durante as aulas, sem arquivo de exercício separado.
